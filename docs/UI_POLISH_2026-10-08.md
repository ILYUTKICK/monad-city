# Monad City — submission polish, 2026-10-08

## Scope and design decision

First submission preparation pass: typography and interface polish. Used the owner-supplied
[design-taste-frontend / redesign-existing-projects skills](https://github.com/leonxlnx/taste-skill)
with two bounded agents: read-only visual audit, and font selection/asset preparation.
Design variance 3, motion 2, density 5. The existing spatial application and Monad palette remain
binding; marketing-page composition and decorative animation guidance is outside this pass.

## Changes

- One primary family: **Instrument Sans**, self-hosted WOFF2 at weights 400/500/600/700.
  Official OFL license, pinned revision, and asset hashes are in
  `src/assets/fonts/instrument-sans/README.md`. Font payload: 141,372 bytes.
- Removed the external Google Fonts import. Regular is preloaded; each face uses font-display swap.
- Reading text 14px, supporting text 12–13px, Navigator title 16px, project title 24px.
  Expanded source/governance disclosures now use readable 12px text. Actual IDs and tool traces
  retain functional mono typography. Counts use tabular figures.
- Navigator reduced from 432 to 384px; Passport widened from 340 to 356px. Solid surfaces,
  quieter neutral borders, smaller shadows, consistent padding and section rhythm.
- Project labels use restrained rounded rectangles. District canvas labels use the same font,
  title case, thinner borders, and clearer separation from roof names. Existing textures refresh
  after font load; a system fallback keeps map startup independent of font loading.
- Source status colors follow the visual contract: blue-gray Observed, amber Claimed, green
  Attested, violet AI-inferred. Record content, eligibility, statuses, sources and snapshots unchanged.
- Map controls clear the open Passport; compact desktop stacks context/controls/legend in the
  available central strip. Desktop height includes header/footer, removing the 36px root scroll.
- AI settings show Enabled/Off; the model remains in its field and badge tooltip. Enabled means
  configured, not a live provider health check. Settings/credentials were not changed.
- About uses a plain project heading and accurately describes the existing optional AI provider.
  Added a concise page description.

map camera framing, dense close-range project layout, source freshness and provider behavior
retain their existing scope. No new dependencies, live feeds or decorative assets were introduced.
